# Corvette.Chat

Чат как встраиваемая библиотека: подключаешь к своему .NET-приложению, вызываешь `services.AddCorvetteChat(dbOptions)` — и получаешь готовую логику чатов, участников, сообщений и непрочитанного.

Пет-проект 2020–2021 годов. 

## Из чего состоит

| Проект                     | Назначение                                           |
| -------------------------- | ---------------------------------------------------- |
| `Corvette.Chat.Data`       | Сущности, контекст EF Core и миграция. PostgreSQL    |
| `Corvette.Chat.Logic`      | Сама библиотека: сервисы, модели и регистрация в IoC |
| `Corvette.Chat.WebService` | Обвязка для проверки: JWT, REST и SignalR-хаб        |
| `Corvette.Chat.Sample`     | Консольный клиент, прогоняющий сценарий целиком      |
| `Corvette.Chat.Tests`      | xUnit, Moq и NFluent на EF In-Memory                 |

Миграции лежат внутри `Corvette.Chat.Data` и применяются при старте веб-сервиса
хостед-сервисом `DbMigrator`.

## Что умеет

- **Чаты.** Приватный на двоих и публичный с владельцем: создание, переименование,
  передача владения, удаление. Всё, что меняет публичный чат, доступно только владельцу.
- **Участники.** Добавление, удаление, выход из чата, список участников.
- **Сообщения.** Отправка, отметка прочтения, пагинация по дате вверх и вниз.
  При входе в чат отдаётся половина прочитанных и половина непрочитанных сообщений —
  чтобы было видно и границу, и контекст перед ней.
- **Непрочитанное.** Счётчик считается для каждого получателя отдельно и приходит
  вместе с сообщением.
- **Доставка.** Отправленное сообщение уходит на все соединения каждого получателя:
  один пользователь может сидеть с нескольких устройств.

## Обвязка

`Corvette.Chat.WebService` — не часть библиотеки, а стенд для её проверки. Пользователь заводится и авторизуется по REST (логин и ключ в обмен на JWT), дальше всё общение идёт через SignalR-хаб на `chat/hub`; 

`Corvette.Chat.Sample` прогоняет сценарий от начала до конца: создать пользователя, получить токен, подключиться к хабу, создать приватный и публичный чат, переименовать, забрать список.

## Почему остановлен

Замысел был в том, чтобы чат подключался к чужому проекту как библиотека. На практике встраивание выходит дороже, чем написать чат под конкретный проект, зная его пользователей и его базу. На этом работа и закончилась.
